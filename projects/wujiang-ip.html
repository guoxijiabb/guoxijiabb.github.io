WUJIANG / CHARACTER DESIGN

乌江佐餐铺｜乌小江品牌 IP 设计

故事 角色 成长 延展

「晒过了，还能脆吗？」

乌小江小时候，总看见乡亲们把青菜头挂在涪陵江边晾晒。后来，他自己经历了风干和三腌三榨，菜身从鲜绿变成金橄榄色。直到第一次跟着乌江榨菜上桌，听见街坊就着白粥咬下那声「咔嚓」，他才放了心。多年后，街坊都叫他「老榨菜头」。他在江边开了一家乌江佐餐铺，招牌上写着：只管配菜。

01｜从一颗青菜头开始

我以重庆涪陵的青菜头为原型，从「乌江」里加一个「小」字，取名「乌小江」，像是街坊顺口喊出来的昵称。造型保留了膨大茎上大小错落的凸包和内收的菜芯，再把一片大叶贴着头型梳下来，变成他的斜刘海。挑眉、歪嘴笑和绿底球鞋，让他看起来爱尝鲜，还有点小得意。

老年形态保留同一片斜刘海和相近的凸包轮廓。菜身变得扁实，主色从青菜绿过渡到腌榨金，再用白眉、翘胡子、木拐杖和健步鞋交代年龄。三视图分别呈现正面的凸包与表情、侧面的菜身厚度，以及背面的叶根和鞋跟结构。

02｜四张身份牌，一段成长故事

菜地小子 → 晒菜学徒 → 榨坊师傅 → 佐餐铺店主。

我把原料到成品的变化拆成四个阶段，再给乌小江安排每个阶段要做的事。他在菜垄里采收，用竹筛和晾架学翻晒，在榨坊转动木榨杆，后来坐镇佐餐铺，给客人的热粥添上一筷榨菜。竹篮、晾架、木榨具和陶坛也被提炼成图标，用来帮助观众读懂场景里的动作。

03｜从佐餐铺延伸到日常

两张主视觉用同一家店串起乌小江的少年和老年形态。开场是小乌小江从柜台后端出一大盘榨菜，结尾是老榨菜头手持乌江鲜脆榨菜丝，在江边店门口迎客。白粥配榨菜和榨菜拌面两张海报，则把镜头拉近到筷子夹起榨菜的那一刻，直接呈现产品怎么吃。

延展时，我把立体角色简化成「开饭啦」「真香」等日常表情，也将同一个形象用到毛绒挂件、冰箱贴和围裙刺绣上。餐桌系列里，青菜头的凸包变成小碟边缘，斜刘海变成叶形筷托，头像轮廓再重复铺成餐垫纹样。角色的几个识别特征，在不同大小和材质上都能继续使用。
